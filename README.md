# Valentine Project

This project is a Python script that plays a song and displays synchronized lyrics on the console. It is designed as a Valentine's Day gift to express love through music and words.

---

## Requirements

- **Python Version**: Python 3.7 or higher is required to run this script.
- **Libraries**:
  - `pygame`: Used for playing the music file.
  - `time`: Used for managing delays and synchronizing lyrics with the music.
  - `os`: Used for file path handling (optional in this script).

---

## How to Install Libraries

Before running the script, ensure you have Python installed on your system. Then, install the required libraries:

1. Open a terminal or command prompt.
2. Run the following command to install `pygame`:
